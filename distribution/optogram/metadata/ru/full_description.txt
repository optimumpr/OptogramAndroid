Optogram — неофициальный клиент Telegram для Android на основе Forkgram.

В настройках Optogram можно скрыть рекламные сообщения, скрыть номера телефонов на поддерживаемых экранах и скрыть сведения об устройстве, которые отправляет клиент. Синхронизация контактов по умолчанию отключена.

Пункт «Быстрая пересылка» открывает окно отправки для сообщений, которые можно пересылать.
